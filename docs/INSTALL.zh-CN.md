# GlyphCopy 插件安装教程

本文说明如何在 Chrome 或 Edge 里以“加载已解压扩展”的方式安装 GlyphCopy。

## 适用场景

GlyphCopy 用于解析超星学习通测试章节中的字体混淆，让页面文本可以复制为原文，而
不是乱码或混淆字符。扩展仅声明 `*.chaoxing.com` 和 `*.xuexitong.com` 站点权限，识别和替换都在本地浏
览器里完成。

## 准备文件

如果你是从 GitHub 下载：

1. 打开仓库首页。
2. 点击 `Code`。
3. 选择 `Download ZIP`。
4. 解压 ZIP。
5. 找到解压后的 `extension` 文件夹。

如果你是在本机开发目录中使用，请选择仓库里的扩展目录：

```text
extension/
```

## Chrome 安装

1. 在地址栏打开：

   ```text
   chrome://extensions
   ```

2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `extension` 文件夹。
5. 页面出现 `GlyphCopy` 卡片后，表示安装完成。
6. 打开超星学习通页面，点击浏览器工具栏里的 GlyphCopy 图标。

## Edge 安装

1. 在地址栏打开：

   ```text
   edge://extensions
   ```

2. 打开左侧或右侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择 `extension` 文件夹。
5. 页面出现 `GlyphCopy` 卡片后，表示安装完成。
6. 打开超星学习通页面，点击浏览器工具栏里的 GlyphCopy 图标。

## 基本使用

1. 进入需要处理的超星学习通测试或章节页面。
2. 点击 GlyphCopy 图标。
3. 点击“扫描”，确认是否发现可疑字体。
4. 点击“刷新识别”，让扩展识别当前页面出现过的混淆字形。
5. 如果有低置信度结果，在识别面板里手动修正并保存。
6. 点击“应用替换”，页面文本会被替换为可复制原文。
7. 如果想撤回当前页面会话中的替换，点击“恢复原文”。

## 自动替换

“自动替换超星页面”默认关闭。开启后，GlyphCopy 会保存一个超星域名级设置。后续
打开超星页面时，扩展会自动扫描、识别缺失字形并应用替换。

建议先在一个页面里手动扫描和识别，确认效果后再开启自动替换。

## 导入和导出映射

GlyphCopy 会把识别结果保存在浏览器本地的 `chrome.storage.local` 中。你可以通过
popup 底部按钮导出映射 JSON，也可以在另一份浏览器 profile 或另一台机器里导入。

映射缓存键名格式为：

```text
glyphcopy:mapping:<fontHash>
```

## 更新插件

如果你下载了新版代码：

1. 替换本地项目文件，或重新解压新版 ZIP。
2. 打开 `chrome://extensions` 或 `edge://extensions`。
3. 找到 GlyphCopy。
4. 点击扩展卡片上的刷新/重新加载按钮。
5. 回到超星页面后刷新网页。

## 卸载插件

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 找到 GlyphCopy。
3. 点击“移除”。

如果你还想清理识别缓存，可以先在浏览器扩展存储里删除 GlyphCopy 的本地数据，或
直接移除扩展后重新安装。

## 常见问题

### 打开 popup 后提示当前页面不可用

确认当前页面是否属于 `chaoxing.com` 或 `xuexitong.com`。GlyphCopy 的站点权限只覆盖这些超星学习通页面，普
通网页、浏览器设置页、扩展管理页都不会注入 content script。

### 扫描不到可疑字体

可能当前页面没有使用字体混淆，或者相关内容还在 iframe/异步区域里加载。可以等待
页面加载完成后重新扫描。

### 识别结果不完全正确

字形识别依赖内置候选字典和当前字体形状。低置信度结果建议手动修正，人工修正会优
先于自动识别结果。

### 应用替换后还能恢复吗

可以恢复当前页面会话里由 GlyphCopy 替换过的文本。刷新页面后，页面会重新从网站
加载；如果开启自动替换，扩展可能会再次自动应用映射。
